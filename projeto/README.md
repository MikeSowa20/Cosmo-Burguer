# Projeto Integrador — Fundamentos de Engenharia de Software

## Nome do sistema
**Cosmo-Burguer — Sistema de Gerenciamento de Pedidos**

## Objetivo
Desenvolver uma solução de software para otimizar o gerenciamento interno de lanchonetes e restaurantes, permitindo organizar pedidos, controlar produtos e ingredientes em estoque, acompanhar as etapas de preparo e identificar possíveis gargalos operacionais.

## Funcionalidades principais
- Cadastro, edição e exclusão de produtos do cardápio.
- Cadastro e gerenciamento de pedidos.
- Edição e cancelamento de pedidos.
- Controle de estoque de ingredientes.
- Atualização automática do estoque conforme os pedidos.
- Esteira de pedidos no estilo Kanban.
- Acompanhamento dos status: Em fila, Em preparo, Pronto e Entregue.
- Atualização dos pedidos em tempo real entre caixa e cozinha.
- Registro do histórico diário de pedidos e alterações.
- Gerenciamento de permissões de usuários.

## Tecnologias utilizadas
- **Front-end:** React com TypeScript.
- **Back-end:** Java com Spring Boot.
- **Banco de dados:** PostgreSQL.
- **Controle de versão:** Git e GitHub.

## Arquitetura do sistema
O sistema utiliza uma arquitetura cliente-servidor dividida em três camadas:

1. **Apresentação:** interfaces do caixa, cozinha e gerenciamento.
2. **Aplicação:** processamento das regras de negócio e gerenciamento dos módulos.
3. **Persistência:** banco de dados local com sincronização em nuvem.

Foi adotada uma abordagem ágil e incremental, inspirada no Scrum, com ciclos de desenvolvimento, divisão de tarefas, acompanhamento por Kanban e controle de versões utilizando GitHub.
